Este es un proyecto personal en el que estoy trabajando actualmente: un **sistema de gestión integral para peluquerías**, pensado para digitalizar y ordenar la administración diaria de este tipo de negocios.

#### Objetivo del proyecto

Muchas peluquerías todavía llevan el control de citas, clientes e inventario en cuadernos o en hojas de cálculo sueltas. Este sistema busca centralizar toda esa información en una sola plataforma web, fácil de usar tanto para el dueño del negocio como para los estilistas.

#### Tecnologías utilizadas

- **PHP** — lógica del backend
- **MySQL** — base de datos
- **Apache (XAMPP)** — entorno de desarrollo y servidor local

#### Funcionalidades principales

- **Gestión de citas**: agenda y control de horarios de cada cliente con cada estilista.
- **Gestión de clientes**: historial de visitas y datos de contacto.
- **Gestión de empleados**: registro de estilistas, horarios y asignación de citas.
- **Servicios y precios**: catálogo de servicios (corte, color, tratamientos, etc.) con sus tarifas.
- **Inventario de productos**: control de stock de productos usados en el salón (shampoo, tintes, insumos, etc.).
- **Reportes de ventas**: resumen de ingresos por período, servicio más solicitado, y desempeño por estilista.
- **Roles de usuario**: permisos diferenciados entre administrador y estilista, para que cada quien vea solo lo que necesita.
